# LeadShot v0.47.0-alpha.1 / Minecraft Java 26.3 / Fabric

LeadShotは弓の偏差照準、最大64体の段階的な常時追跡、簡易索敵枠、任意の自動照準・発射補助を提供する実験的なクライアントMODです。

## v0.47の改善

- **射撃検査の実弾速統一**：逆算で得た「必要初速」をそのまま命中検査に使う誤差を修正。最大チャージ時の3.0ブロック/tickに正規化した初速と、射手から引き継ぐ速度で衝突・遮蔽・3モデル・軌道表示を評価します。
- **同tickの遮蔽再検査を削減**：軽量索敵枠、通常索敵、照準候補が同じ対象へ複数回のレイキャストを行う重複を抑制。次tickには新しく検査します。
- **v0.46の未反映改善を統合**：自動照準中でもマウスで別対象へ切替、エリトラ射手の発射原点と速度継承を補正、飛行時間の根探索を含みます。

操作はゲーム内のOキーから日本語設定画面を開きます。I=ロック、P=対象変更、K=解除、J=自動照準切替、H=HUD切替。自動発射補助は明示的に有効化し、弓を最大まで引いて右＋左クリック長押しです。
