# LeadShot v0.44.0-alpha.1 — Fabric Minecraft 26.3

日本語の戦術HUD、最大64体の段階的追跡・予測、弓の最大チャージ時の偏差照準、自動追従・発射補助を備えたクライアントMODです。v0.44では高速機動する飛行対象向けの先読みと数値精度、日本語表示、照準旋回速度の上限、マルチプレイでの連続追従による発射待機を改善しました。

[更新・操作ガイド](UPGRADE_GUIDE_v044.md) / [技術仕様](SPEC_v044.md)

**ビルド状況:** Java 21での数学・設定テストと模擬API検査まで。実Fabric 26.3のJARビルドやマルチプレイの動作確認は未実施です。


LeadShotはクライアント側の弓用火器管制HUD MODです。AIM/PRED、READY、CENTER/RADAR索敵、最大64体の段階式事前計算、手動ロック、実験的な自動照準／発射補助を含みます。

## v0.43.0の改善

1. **マルチプレイ照準同期**：視点の動きを標準の回転更新で通知した後に標準の弓使用終了を送信。自動照準と補助発射のタイミング調整。
2. **自動再チャージ補助**：右＋左クリック保持で弓が再び使用されない場合、Minecraft標準のアイテム使用経路を再試行（6tick間隔制限）。
3. **中央優先索敵**：モブ当たり判定がクロスヘアに入った場合を重視。CENTERだけでなくRADARにも適用。
4. **SCAN BOX**：設定6ページ目でOFF/VISIBLE/ALL CONTACTS。どのモードでも弓を引いていない間から最大64体の簡易枠を表示。

自動照準は遮蔽のない幾何学的な接触予測が成立すれば追従し、3モデルの完全一致までは要求しません（READY・自動発射は従来どおり厳密に判定）。

## 操作

- O：設定（フレンドキーと競合する場合はキー割り当て変更）。6ページ目でSCAN BOX切替。
- G：照準とSCAN BOXの表示。H：戦闘機風／従来HUD切替。
- I：手動ロック。P：次の対象。K：ロック解除。J：自動照準ON/OFF。
- 7ページ目で発射補助ON、**右＋左クリック保持**。十分引き絞った弓・敵対モブ・弾道CLEAR・READYが必要。
